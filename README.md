# NeerNet Intelligence

## Run locally
1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Optional AI: copy `.env.example` to `.env`, then add your own Gemini API key. Never upload `.env`.
5. Run `npm start`.
6. Open `http://localhost:3000`.

Without a Gemini key, transparent rule-based analysis is used; do not describe that mode as generative AI.

## Features
Responsive mint/teal design, API-backed reports, local JSON persistence, explainable preliminary prioritization, optional Gemini API integration, duplicate warning for human review, live dashboard counts.

## Limitations
Prototype only: it does not test water, verify reports, or contact authorities. Scores are not scientifically validated risk ratings. JSON storage is for local demo use. Before public deployment add authentication, authorization, rate limiting, a production database, privacy controls and monitoring. Check official hackathon rules about AI-assisted coding, APIs, attribution and pre-existing code; disclose assistance when required.
